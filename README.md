# LameRegressionTesting

Регрессионное тестирование mp3-кодировщика [LAME](https://lame.sourceforge.io/):
сравнение двух версий (**3.100** — базовая, **4.0** — проверяемая) по

- **скорости кодирования**;
- **бинарному различию** результатов (факт различия mp3-файлов).

Тест рекомендуется проводить на двух WAV исходных аудиофайлах, один из которых (с эталонным, зашитым в скрипт
названием track1_speech.wav) содержит запись голоса без фоновых шумов, а второй (с эталонным, зашитым в скрипт
названием track2_music.wav) представляет "тяжёлое" аудио с плотным заполнением спектра частот, например музыка.

По итогам прогона формируется HTML-отчёт с результатами, условиями тестирования и логом выполнения.

## Быстрый старт

Готовая сборка (без установки .NET) и пример отчёта — на странице
[Releases](https://github.com/ViktorKorneplod78/LameRegressionTesting/releases).

Запуск из исходников: Windows 10/11 x64, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
(`winget install Microsoft.DotNet.SDK.8`).

1. Положите входные WAV в `input\` (в репозитории их нет, см. [input/README.md](input/README.md)).
2. Запустите:

```bat
run_tests.bat
```

Вместо указанных версий LAME можно положить в директорию lame любые другие пары версий, рядом с exe
должны быть их dll библиотеки, иначе не запустятся.  В run_tests.bat указать актуальные пути:
```
set OLD=lame\3.100\lame.exe
set NEW=lame\4.0\lame.exe 
```

Скрипт соберёт приложение, выполнит 10 сценариев и откроет отчёт
`reports\<дата_время>\report.html`. Ключ `/noopen` — не открывать отчёт (для автоматического запуска).
Код возврата: `0` — все сценарии выполнены, `1` — были ошибки, `2` — ошибка сборки, аргументов или нет входных файлов.

## Структура

```
lame\3.100\         LAME 3.100 x64 (RareWares, сборка с libsndfile)
lame\4.0\           LAME 4.0 x64 (RareWares)
input\              исходная пара WAV
src\                C#-приложение (.NET 8)
run_tests.bat       запуск всех сценариев
reports\            результаты прогонов (создаётся автоматически, не в git)
```

## Сценарии

5 настроек кодирования × 2 входных файла = 10 сценариев:

| Настройка | Параметры LAME | Что проверяет |
|---|---|---|
| CBR 128 | `-b 128` | постоянный битрейт, режим по умолчанию |
| CBR 320, q0 | `-b 320 -q 0` | максимальный битрейт, самый медленный и качественный алгоритм |
| VBR V2 | `-V 2` | переменный битрейт |
| ABR 160 | `--abr 160` | средний битрейт |
| Mono 64 | `-b 64 -m m --resample 22.05` | моно, ресемплинг, MPEG-2 |

Сценарии, версии LAME, число замеров и порог замедления задаются в `run_tests.bat`.

## Как проводится тест

Для каждого сценария приложение:

1. делает прогревочный запуск каждой версии (не учитывается);
2. выполняет N замеров (по умолчанию 5), чередуя версии: old, new, old, new…;
3. измеряет полное время процесса `lame.exe` и его процессорное время; в отчёт идут медиана, минимум и среднее;
4. сравнивает результаты:
   - **файлы** — совпадает ли SHA-256 mp3-файлов целиком;
   - **аудиоданные** — совпадает ли SHA-256 без первого кадра с Xing/LAME-тегом. LAME записывает туда строку
     своей версии, поэтому файлы разных версий различаются всегда, и эта проверка показывает,
     изменилось ли само кодирование.

Замедление новой версии больше порога (по умолчанию 10%) выделяется в отчёте.

## Запуск приложения вручную

```bat
build\LameRegression.exe run --run-dir reports\manual --name my_test --input input\track2_music.wav ^
    --options "-b 192" --old lame\3.100\lame.exe --new lame\4.0\lame.exe --iterations 3
build\LameRegression.exe report --run-dir reports\manual --threshold 10
```

`run` выполняет один сценарий и сохраняет результат в `results\<name>.json`;
`report` собирает все результаты из директории прогона в `report.html`.
Лог всех вызовов пишется в `run.log` той же директории.

## Структура кода

| Файл | Назначение |
|---|---|
| `Program.cs` | разбор аргументов, команды `run` и `report` |
| `ScenarioRunner.cs` | выполнение сценария: прогрев, замеры, сравнение |
| `LameRunner.cs` | запуск `lame.exe`, замер времени, таймаут |
| `Mp3Compare.cs` | SHA-256 файла целиком и аудиокадров без тега |
| `WavInfo.cs` | чтение параметров WAV из заголовка |
| `EnvironmentInfo.cs` | сведения об ОС, процессоре, памяти |
| `ReportWriter.cs` | HTML-отчёт |
| `Logger.cs` | лог в консоль и файл |
| `ScenarioResult.cs` | классы с результатами сценария (сохраняются в JSON) |
